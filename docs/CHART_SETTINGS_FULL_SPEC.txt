--------------------------------------------------------------------------------------
3.1 CHART SETTINGS
--------------------------------------------------------------------------------------

OPTION: Chart Type
VALUES: Candlestick / Line / Histogram / Combined
BEHAVIOR:
- Defines how price data is visually represented.
- Candlestick: shows OHLC with body + wicks.
- Line: shows close price only.
- Histogram: vertical bars representing values.
- Combined: multiple representations layered.

OPTION: Zoom Behavior
VALUES: Time Axis / Price Axis / Both / Zoom Speed
BEHAVIOR:
- Time Axis: zoom stretches/compresses horizontal scale.
- Price Axis: zoom stretches/compresses vertical scale.
- Both: zoom affects both axes simultaneously.
- Zoom Speed: controls sensitivity of zooming.

OPTION: Scroll Behavior
VALUES: Scroll Speed / Smooth Scroll
BEHAVIOR:
- Scroll Speed: horizontal movement speed of chart.
- Smooth Scroll: enables animated scrolling.

OPTION: Visible Candles Count
BEHAVIOR:
- Defines how many candles are rendered at once.
- Higher values require more GPU/CPU.

OPTION: Auto Fit
VALUES: On/Off
BEHAVIOR:
- Automatically adjusts price axis to fit visible candles.

OPTION: Mouse Wheel Behavior
VALUES: Zoom / Scroll
BEHAVIOR:
- Zoom: wheel zooms chart.
- Scroll: wheel moves chart horizontally.
